# 🐣 Chilzy — StudyMitra

**A personality-based virtual study companion powered by Generative AI + RAG**

Chilzy is your virtual study buddy that tracks your study sessions, reacts with personality (motivating or gently scolding), and helps you learn smarter using AI — built as a CSE core OOPs PBL project.

---

## 📖 About

Students often struggle to stay consistent with studying and lack a personalized way to revise. Chilzy solves this by combining gamification (XP, Levels, Streaks) with an AI-powered chatbot that explains topics, quizzes you, and highlights your weak areas — all based on **your own notes**, using Retrieval-Augmented Generation (RAG).

Officially listed as: **Group-8 — "Personalized Study Assistant Using Generative AI and RAG"**

## ✨ Features

- 🎮 **Gamification** — XP, Levels, Streaks
- 🧠 **AI Study Chatbot** — Explain, Quiz, Revision modules
- 📚 **RAG-based knowledge base** — built from your own uploaded notes/PDFs
- 🌐 **Multilingual** — Hindi + English support
- 🔊 **Voice-over** — Chilzy speaks its reactions
- 😊 **Mood-based reactions** — personality-driven responses
- ❄️ **Streak freeze** — miss one day, streak stays safe
- 📅 **Daily challenge** — questions from what you're actually studying
- 📊 **Weekly recap** — study summary every week
